MÓDULO DE ACTIVOS

Registrar activo

Añada nuevos activos al sistema para permitir su gestión y mantener el inventario al día.

▣

Datos del nuevo activo

Los campos marcados con * son obligatorios. El sistema validará la información antes de crear el registro.

Debe ser único. Solo letras, números, punto, guion y barra.
Use punto decimal y máximo 2 decimales.
¿No aparece? Administrar catálogos

APRENDA EL PROCESO

Registrar un activo en 3 pasos

  1. 1IdentifíqueloIngrese el número de identificación y una descripción clara.
  2. 2ClasifíqueloElija categoría, estado, ubicación y modo de adquisición.
  3. 3Revise y registreCompruebe los datos antes de confirmar.
Ejemplo de entrada de datos:
Número: ACT-2026-0001
Descripción: Computadora portátil de escritorio
Marca: Dell · Modelo: OptiPlex 7010
Serie: SN-8841207
Precio: 450000.00
Trazabilidad: el sistema registra quién creó el activo, la fecha y hora exactas y el ID del activo.
